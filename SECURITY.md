# Segurança

## Português

Se encontrou uma vulnerabilidade no Adelino ou no Albelinostein, comunique-a
através do formulário de suporte:
<https://albelino.plimswitzzer.com/suporte/>

- Se o formulário tiver um assunto dedicado a segurança, escolha-o. Se não
  tiver, descreva no texto que se trata de uma questão de segurança.
- Não publique os detalhes antes de existir uma correção.
- Inclua a versão, o sistema operativo e os passos para reproduzir.
- Não é prometida nenhuma recompensa.
- Só o formulário é um canal de suporte.

Ainda não foi publicada nenhuma versão. Os limites das proteções (o que o
Adelino não protege) estão descritos no
[documento técnico](docs/whitepaper.pt.md#9-fronteiras-de-confiança-e-o-que-o-adelino-não-protege).

## English

If you find a vulnerability in Adelino or Albelinostein, report it through the
support form: <https://albelino.plimswitzzer.com/suporte/>

- If the form has a subject for security, choose it. If it does not, say in
  the text that it is a security matter.
- Do not publish details before a fix exists.
- Include the version, the operating system and steps to reproduce.
- No bounty is promised.
- The form is the only support channel.

No version has been published yet. The limits of the protections (what
Adelino does not protect against) are described in the
[whitepaper](docs/whitepaper.en.md#9-trust-boundaries-and-what-adelino-does-not-protect-against).
