# Segurança

## Português

Se encontrou uma vulnerabilidade no Adelino ou no Albelinostein, comunique-a
em privado no GitHub, em «Report a vulnerability» no separador Security deste
repositório: <https://github.com/plimnew/Albelinostein/security/advisories/new>. Só a equipa vê o relato.

- Não publique os detalhes antes de existir uma correção.
- Inclua a versão, o sistema operativo e os passos para reproduzir.
- Não é prometida nenhuma recompensa.
- Os únicos canais oficiais são este relato privado, para segurança, e o
  servidor do Discord <https://discord.gg/AyZHZPtkHk>, para o resto. Não publique
  vulnerabilidades no Discord. A equipa nunca pede chaves, palavras-passe
  nem pagamentos por mensagem privada, e não usa email para suporte.

A versão 0.1.0 foi publicada a 26 de novembro de 2026. Os limites das proteções (o que o
Adelino não protege) estão descritos no
[documento técnico](docs/whitepaper.pt.md#9-fronteiras-de-confiança-e-o-que-o-adelino-não-protege).

## English

If you find a vulnerability in Adelino or Albelinostein, report it privately
on GitHub, under “Report a vulnerability” in this repository's Security tab:
<https://github.com/plimnew/Albelinostein/security/advisories/new>. Only the team sees the report.

- Do not publish details before a fix exists.
- Include the version, the operating system and steps to reproduce.
- No bounty is promised.
- The only official channels are this private report, for security, and
  the Discord server <https://discord.gg/AyZHZPtkHk>, for everything else. Do not post
  vulnerabilities on Discord. The team never asks for keys, passwords or
  payments in private messages, and does not use email for support.

Version 0.1.0 was published on 26 November 2026. The limits of the protections (what
Adelino does not protect against) are described in the
[whitepaper](docs/whitepaper.en.md#9-trust-boundaries-and-what-adelino-does-not-protect-against).
