# Registo de alterações / Changelog

## 0.1.1 — 2026-11-27

**Versão 0.1.1 para macOS, publicada a 27 de novembro de 2026. / Version 0.1.1 for macOS, published on 27 November 2026.**

- Aplicação Albelinostein para macOS com Apple Silicon, numa imagem de disco (`.dmg`) assinada com Developer ID e notarizada pela Apple / The Albelinostein app for macOS on Apple Silicon, as a disk image (`.dmg`) signed with Developer ID and notarised by Apple
- Não funciona em Macs com processador Intel / It does not run on Macs with an Intel processor
- No macOS ainda não há sandbox de comandos nem programa de linha de comandos / On macOS there is no command sandbox and no command-line program yet

Linux e Android continuam na 0.1.0. / Linux and Android stay at 0.1.0.

## 0.1.0 — 2026-11-26

**Versão 0.1.0, publicada a 26 de novembro de 2026. / Version 0.1.0, published on 26 November 2026.**

O que inclui, ao nível dos títulos / What it contains, at headline level:

- Motor e programa de linha de comandos `adelino` / The `adelino` engine and command-line program
- Aplicação Albelinostein para computador / The Albelinostein desktop app
- Política determinística, com modos, concessões e regra de contaminação / Deterministic policy with modes, grants and the taint rule
- Aprovações assinadas por pessoas, no terminal ou num dispositivo emparelhado / Human-signed approvals, from the terminal or a paired device
- Registo assinado e encadeado por somas, com `verify`, exportação e verificação fora da máquina / Signed, hash-chained ledger with `verify`, export and outside verification
- Sandbox de comandos no Linux / Command sandbox on Linux
- Desfazer escritas de ficheiros / Undo for file writes
- Memória, mapa da pasta de trabalho e skills criadas a partir de documentos / Memory, a map of the working folder, and skills made from documents
- Limites de gasto e tarefas agendadas / Spending limits and scheduled requests

Estado: Linux validado pelo guião de aceitação; macOS, Windows, Android e iOS por validar.
